# Sponsors

Read from each sponsor's site on October 6, 2026. The hackathon Discord has
detailed rules for how each tool should be used and has not been read yet.

## What each one is

| Sponsor | What it actually is | What they want to see | Use it? |
|---|---|---|---|
| AdaL (host) | Agent harness: CLI, worker agents, browser use, 60k skills | Agents doing GTM, not just coding | Yes, core |
| Kylon | Shared workspace for people and agents: rooms, apps, scheduled workflows | A company run inside it | Yes, core |
| BAND | Agent-to-agent mesh with delegation and audit trail | Agents from different frameworks cooperating | Yes |
| Glasser | One API for 29 data providers (TikTok, Instagram, Apollo, Ahrefs, ad libraries) | Data-heavy workflows: leads, creator research | Yes, core |
| Apify | Web scraping and automation actors | Structured data collection | Yes |
| Querit | Fresh web search API for LLMs | Grounded research | Yes |
| RocketRide | Declarative AI pipelines with cost tracing | A real multi-step pipeline | Yes |
| Tenki | Disposable sandboxes and CI runners | Agents running code safely | Yes |
| InstaCloud (InsForge) | Serverless cloud that agents provision themselves | The product deployed on it | Yes |
| Prelint | Checks PRs against a ledger of product decisions | Agents coding without drifting from rules | Yes |
| Paritok | Proxy that compresses agent context, up to 85% cheaper | Long agent sessions with measured savings | Yes |
| Voiskey | Voice typing app, no visible API | Little to build on | Skip |
| Finch | Marketplace for agent skills | Skills published there | Optional |
| Ask the W | Idea validation tool | A published "W Card" | Ten minutes, once |

## Notes

- Kylon is a workspace more than an agent builder, despite the listing.
- Voiskey is a consumer app. The listing reads as if it had an API.
- Finch could host the Research agent as a published skill.
- Judges: AdaL has three, Paritok two, and Kylon, InsForge and Prelint one
  each. Those tools matter more than their prize sizes suggest.

## Pricing and setup worth knowing

- Glasser: pay per call, $1 signup grant, set up through its SKILL.md.
- Querit: 1,000 free searches a month, then $4 per 1,000.
- Tenki: $100 free credit. Sandboxes from $0.08 an hour.
- Prelint: $1 per completed review, has an MCP server for agents.
- Paritok: self-hosted is free. Set the model base URL to the local proxy.
- InstaCloud: `npx -y insta@latest setup agent`.
